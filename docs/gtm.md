# GTM (Go-to-Market)

**Status:** design intent.

## Positioning

**"Security tools claim; agentdrill proves."** The proof layer of the agentsec-ecosystem — the reproducible,
honest benchmark for what agent defenses actually stop.

## Wedge

Radical honesty. In a market that oversells detection, published results **including the misses** are the
differentiator — and the benchmark becomes the reference others must submit to (standards-authorship moat).

## Audience

1. Security/platform teams running agent workloads (P2 Ravi) — evidence for their own stack.
2. Ecosystem builders/embedders (P5 Alex) — a drill harness for their controls.
3. The public — a reproducible record of what stops what.

## Motion

- **Dogfood-first:** the ecosystem's own CI is gated by agentdrill from Wave 0 (a drill needs a target).
- **Benchmark-as-funnel:** reproduce-the-benchmark is the entry; the drill is the product.
- **Community packs:** reviewed like code (R11); external submissions via PR (F57).
- **Design partners:** run the drill against their stacks; publish their honest rows.

## Honesty rules (marketing)

No "injection solved"; no detection-rate claims; no composite security score; misses always published;
limitations register with every release.

## Launch (Wave 0)

One ecosystem install; the meta-MVP demo (gate a policy PR with a real drill). Accompanying articles:
[docs/articles](articles/README.md).
