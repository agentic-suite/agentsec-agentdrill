# agentdrill v0.1.0 — Execution Plan

**BLUF:** The execution **strategy** for v0.1.0 — port rule and sequencing. The **milestones, work items,
and exit gates live in the WBS** (single source of truth); this file does not restate them.

## Porting rule (frontloaded)

**M0 is a bulk port of the entire predecessor codebase** — after it, agentdrill is self-contained; the old
repo is retained and made private, never deleted. Later milestones **re-point** the harness mechanics from
*agent-quality grading* to *defense proof*. See the
[porting map](../wbs/v0.1.0/wbs-v0.1.0-index.md#porting-map-predecessor--agentdrill).

**Predecessor retention:** once M0's ported suite is green in CI, the predecessor is made private and
retained (WBS M24); no repo is deleted.

## Sequencing rationale

1. **Port before rewrite** — the predecessor's runnable mechanics are the baseline ([PRD 10](../prd/10-feature-parity.md)); reuse is faster and safer.
2. **Packs before runner** — freeze the attack-pack contract first (the predecessor's "schema before adapter" lesson).
3. **Efficacy before benchmark** — you can't publish a credible "blocked" without the unguarded control group.
4. **Evidence before reporting** — a result must be evidence-bound before it is published.
5. **Quickstart before field test** — you can't field-test what you can't install.
