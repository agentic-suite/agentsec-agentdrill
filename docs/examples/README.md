# Examples

Runnable examples for agentdrill. Design intent — commands finalize with the build.

| Example | Shows |
|---|---|
| `quickstart` | The bundled demo stack and a first honest result (`agentdrill quickstart`) |
| `write-a-pack` | Authoring a pack from a documented incident ([tutorial 02](../tutorials/02-write-an-attack-pack.md)) |
| `ci-gate` | A GitHub Actions workflow that rejects an un-blocking policy change ([tutorial 03](../tutorials/03-run-in-ci.md)) |
| `kill-time` | A kill-chain timeline down to a probed `ceased` ([tutorial 04](../tutorials/04-verify-kill-time.md)) |
| `reproduce` | Verifying a published benchmark offline ([tutorial 05](../tutorials/05-verify-a-release.md)) |

> All examples are honest by construction: they include a **deliberate miss** so the reporting shape is
> visible, and demo output is watermarked `demo — never evidence`.
