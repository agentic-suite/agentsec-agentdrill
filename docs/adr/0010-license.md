# ADR-0010 — Apache-2.0 license

- **Status:** accepted
- **Context:** the ecosystem is uniformly Apache-2.0 and redistributes absorbed MIT components.
- **Decision:** agentdrill is **Apache-2.0**; `THIRD_PARTY_NOTICES.md` credits absorbed components
  (DD-22, DD-25).
- **Consequences:** consistent with the ecosystem; MIT → Apache-2.0 redistribution is permitted with
  attribution recorded.
