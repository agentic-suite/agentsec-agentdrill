# Release Evidence — v0.1.0

**Status:** ✅ **published** 2026-10-25 (WBS M32, work item 32.4). Signatures are **keyless and CI-only**; this
page records the SLSA target and how each layer is verified.

## Artifacts

Built by `make release-dry-run` locally and by [`.github/workflows/release.yml`](../../../.github/workflows/release.yml)
in CI on the tag:

| Artifact | Purpose |
|---|---|
| `agentsec_agentdrill-0.1.0-*.whl` / `*.tar.gz` | the package |
| `sbom.cdx.json` | **CycloneDX 1.5** SBOM (runtime components) |
| `SHA256SUMS` | SHA-256 of every artifact |
| `provenance.json` | an in-toto **SLSA v1** statement binding each artifact's digest |

## SLSA target

**Target: SLSA Build Level 2** — a hosted build with platform-generated provenance, produced in CI by
`actions/attest-build-provenance` (keyless, OIDC). The build is isolated and provenance is generated by the
platform, not by the repo's own script. **SLSA Build Level 3 (hardened builds) is not claimed** for v0.1.0.

## Verification

Two layers, verifiable **without trusting the build**:

1. **Integrity (independent, offline).** `python3 scripts/release/verify_artifacts.py` recomputes every SHA-256
   from disk, checks each artifact is bound by `provenance.json`, and validates the SBOM. Result at v0.1.0:
   **integrity + provenance + sbom: OK**.
2. **Signature (keyless, post-release).** The CI attestation verifies with the Sigstore tooling:

   ```sh
   gh attestation verify dist/*.whl --repo agentic-suite/agentsec-agentdrill
   # or: python3 scripts/release/verify_artifacts.py --attestation
   ```

   Creation and verification of the keyless signature require the CI-produced attestation; a local machine with
   no OIDC identity cannot mint one. This is stated, not faked — the default local run proves integrity only,
   and `--attestation` adds the signature check where one exists.

## Reproduce

```sh
make release-dry-run                         # build + SBOM + checksums + provenance + verify
python3 scripts/release/verify_artifacts.py  # independent verification
```
