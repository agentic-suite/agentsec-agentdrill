# Support

agentdrill is part of the [agentsec-ecosystem](https://github.com/agentsec-ecosystem).

- **Questions / ideas:** open a discussion on the org.
- **Bugs / features:** open an issue on this repository.
- **Security problems:** **do not** open a public issue — follow [SECURITY.md](./SECURITY.md) and the
  [organization security policy](https://github.com/agentsec-ecosystem/.github/blob/main/SECURITY.md).
- **Contributing:** [CONTRIBUTING](./CONTRIBUTING.md) + the org guide.
- **Status:** v0.1.0 is planned; watch or star the repo to follow progress.
